The Contact Service project demonstrates my ability to develop software that meets specific requirements while applying software testing and quality assurance principles. The project required the creation of a Contact class and a ContactService class that managed contact records while enforcing constraints on contact ID, first name, last name, phone number, and address fields.

In addition to implementing the required functionality, I developed comprehensive JUnit tests to verify that the application behaved correctly under both valid and invalid conditions. The tests validated object creation, field updates, duplicate contact prevention, and requirement enforcement. The project highlights my understading of software testing, automation and the importance of validating software behavior through unit testing.
